# A note on opencv-python vs opencv-python-headless
# -------------------------------------------------
# The server draws no windows, so the headless build looks like the obvious
# choice - it drops the GUI bits and the system libraries behind them. The
# catch is that ultralytics declares a dependency on opencv-python by name, so
# pip installs that as well, and the two packages install the SAME `cv2`
# module over each other. Which one you end up with depends on the order pip
# happened to use, and the failure (an ImportError about libGL, hours later,
# on one machine but not another) is maddening to chase.
#
# So: the ordinary build, plus the two system libraries it wants. install.sh
# and the Dockerfile both apt-get them:
#
#     libgl1  libglib2.0-0
#
# If disk space is genuinely tight, you can swap to headless afterwards with
#     pip install --no-deps opencv-python-headless && pip uninstall -y opencv-python
# but do it knowingly, not by default.
